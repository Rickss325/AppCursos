# AppCursos

Aplicación de escritorio móvil creada con Kivy y KivyMD para gestionar cursos.

Requisitos
- Python 3.11+ (o 3.12) instalado
- Instalar dependencias:

```bash
python -m pip install -r requirements.txt
```

Ejecutar

```bash
python curso_2.py
```

Notas
- Si usas un entorno virtual, actívalo antes de instalar dependencias.
- Este repositorio incluye `curso_2.py` como punto de entrada.
